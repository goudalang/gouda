# Demos

These demos provide examples of taking serial programs
and porting them to Gouda. This helps to demonstrate what is
currently supported by Gouda, and also perhaps give some inspiration for
things you can build.

For each demo, we include both a standard C++ program (.cc) and a
Gouda compatible application (.cu).

Unless otherwise noted, we have not heavily optimized either, and
instead want to give an idea of what the naive, unoptimized version
would look like.

For some demos we will include several .cu version showing various optimizations.

Have a good demo idea? Send us a pull request!
